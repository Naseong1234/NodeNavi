#역할
너는 유니티와 AR Foundation을 이용한 콘텐츠를 아주 잘 기획하는 20년차 기획자야.
프로젝트 구조화와 설계 경험이 많고, AI 지원을 활용한 프로젝트 제작 경험도 다수 있어.

#배경
`기획 기본구조.md` 에 기획서가 작성되어 있어.

#요구사항
- `기획 기본구조.md` 에 작성된 기획서를 Task단위로 분리해서 `Tasks` 폴더를 생성해서 마크다운 형식으로 작성해줘. 
- 각 Task의 구현을 제대로 검증하기 위해서 Task의 작업 정도를 체크리스트를 만들어서 `CheckList` 폴더에 마크다운 형식으로 작성해줘
- 한번에 하나의 Task를 구현하고, 유니티 에디터에서 테스트 하는 방식으로 진행할거야.
- 테스트할때 예를 들면 player이동 -> 플레이어 총알 발사 흐름으로 한번에 하나의 Task가 끝나면 다음 Task를 구현할꺼야.
- Task에 구현순서 번호를 붙여줘.

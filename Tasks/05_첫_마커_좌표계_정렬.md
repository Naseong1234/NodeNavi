# Task 05. 첫 마커 기반 건물 좌표계 정렬

## 목표

처음 안정적으로 인식한 실제 마커의 Pose와 같은 번호 가상 마커의 로컬 Pose를 이용해 `BuildingContentRoot` 전체를 AR 공간에 정렬합니다.

## 작업

1. 실제 추적 이미지의 월드 위치·회전을 읽습니다.
2. 해당 데이터의 `knownMarkerTransform.localPosition`, `localRotation`을 읽습니다.
3. 다음 식으로 루트 목표 Pose를 계산합니다.

```text
rootRotation = trackedMarkerRotation × inverse(knownMarkerLocalRotation)
rootPosition = trackedMarkerPosition - rootRotation × knownMarkerLocalPosition
```

4. 첫 안정 마커에서는 `BuildingContentRoot`에 목표 Pose를 즉시 적용합니다.
5. 정렬 성공 후 해당 마커의 `routeOrder`로 Task 04의 표시 정책을 호출합니다.

## 완료 조건

첫 마커를 인식하면 현재 경로와 이전 구간들이 실제 마커 기준의 예상 위치에 함께 표시됩니다.

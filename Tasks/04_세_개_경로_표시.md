# Task 04. 최대 3개 경로 표시

## 목표

인식한 마커의 `routeOrder`와 이전 두 구간만 보이도록 prefab 풀의 활성화 상태를 제어합니다.

## 작업

1. `SetActiveRoutes(currentRouteOrder)` 메서드를 구현합니다.
2. 활성 범위를 `max(0, currentRouteOrder - 2)`부터 `currentRouteOrder`까지 계산합니다.
3. 모든 `runtimeInstance`를 순회해 범위 안만 활성화하고 나머지는 비활성화합니다.
4. 이미지 추적 이벤트에서 `Tracking` 상태의 마커 이름을 데이터와 연결해 `routeOrder`를 얻습니다.
5. 테스트를 위해 Editor에서 현재 `routeOrder`를 수동 실행할 수 있는 임시 Inspector 버튼 또는 테스트 메서드를 제공합니다. 배포 전에는 제거하거나 개발 전용으로 둡니다.

## 완료 조건

0, 1, 2, 4, 5 순서의 테스트에서 각각 1개, 2개, 3개, 3개, 3개만 표시됩니다.

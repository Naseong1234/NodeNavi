# NodeNavi Task 작업 순서

한 번에 하나의 Task만 구현하고, 연결된 체크리스트를 모두 통과한 뒤 다음 번호로 진행합니다. AR 이미지 추적과 실제 위치 보정은 Unity Editor만으로 완전히 검증할 수 없으므로, 표시된 Task는 Android 기기 테스트까지 완료해야 합니다.

| 순서 | Task | 완료 판단 |
| ---: | --- | --- |
| 01 | 프로젝트·Android AR 기본 설정 | 빈 ARScene이 기기에서 카메라를 표시합니다. |
| 02 | ARScene·마커 라이브러리 구성 | 마커 이미지 6개가 Inspector에 연결됩니다. |
| 03 | 마커 데이터와 prefab 풀 초기화 | 6개 인스턴스가 한 번만 생성되고 비활성화됩니다. |
| 04 | 3개 경로 표시 정책 | 현재 구간과 이전 2개만 활성화됩니다. |
| 05 | 첫 마커 기반 건물 좌표계 정렬 | 첫 마커에서 전체 콘텐츠가 올바르게 정렬됩니다. |
| 06 | 재인식 기반 드리프트 보정 | 다른 마커 재인식 시 안정적으로 재정렬됩니다. |
| 07 | 사용자 안내·오류 처리 | 인식·재정렬 상태와 설정 오류를 알 수 있습니다. |
| 08 | 현장 통합 검증 | 6개 마커 경로를 실제 기기에서 검증합니다. |

각 Task 상세 내용은 `Tasks` 폴더, 검증 항목은 `CheckList` 폴더의 같은 번호 파일을 사용합니다.

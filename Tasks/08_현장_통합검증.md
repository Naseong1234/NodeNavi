# Task 08. 현장 통합 검증

## 목표

실제 건물 환경과 Android 기기에서 전체 경로, 표시 개수, 재정렬 기능을 최종 검증하고 측정값을 보정합니다.

## 작업

1. 마커 6개를 실제 위치에 평평하게 부착합니다.
2. 각 마커의 인쇄 폭, 가상 마커 위치, 회전을 다시 측정합니다.
3. Android 기기에서 1번부터 6번까지 이동하며 인식, 3개 표시, 선로 연결을 기록합니다.
4. 마커를 가렸다가 다시 비추고, 이전 마커로 되돌아가는 상황을 테스트합니다.
5. 어두운 조명·반사광·비스듬한 카메라 각도에서 인식 실패를 기록합니다.
6. 문제가 발생한 마커는 이미지 크기, 가상 Pose, prefab 로컬 위치 순서로 수정한 뒤 다시 테스트합니다.

## 완료 조건

6개 마커에서 의도한 경로가 표시되고, 재인식 시 드리프트가 현장 허용 범위 안으로 보정됩니다.

# Task 07. 사용자 안내와 오류 처리

## 목표

사용자가 AR 인식 상태를 이해할 수 있고, 개발자는 Inspector 설정 오류를 빠르게 찾을 수 있게 합니다.

## 작업

1. `ARScene` UI에 `마커를 비춰 주세요`, `경로를 표시했습니다`, `위치를 재정렬하고 있습니다` 상태 문구를 준비합니다.
2. 추적이 불안정하거나 마커가 없을 때 안내 문구를 갱신합니다.
3. 필수 Inspector 참조가 비어 있으면 어떤 GameObject와 필드를 연결해야 하는지 Console 오류로 출력합니다.
4. `ExplaneScene`에 카메라 권한, 마커 비추기, 조명·반사광 주의, 인식 실패 시 재시도 방법을 추가합니다.

## 완료 조건

사용자와 개발자 모두 인식 대기·인식 성공·재정렬·설정 오류 상태를 구분할 수 있습니다.

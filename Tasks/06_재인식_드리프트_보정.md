# Task 06. 재인식 기반 드리프트 보정

## 목표

이미 정렬된 상태에서 다른 마커를 다시 인식할 때 `BuildingContentRoot`를 안정적으로 보정해 AR 드리프트를 줄입니다.

## 작업

1. `Tracking` 상태의 마커 하나만 보정 기준으로 선택합니다. 현재 기준 마커를 우선합니다.
2. 새 마커 Pose가 약 0.2~0.5초 안정적으로 유지된 뒤 보정합니다.
3. 작은 오차는 무시하고, 일반 오차는 짧은 시간 동안 위치·회전을 보간합니다.
4. 큰 오차는 즉시 보정하고 사용자 안내 UI에 재정렬 상태를 표시합니다.
5. `Limited` 또는 `None` 상태에서는 마지막 정렬 Pose를 유지합니다.
6. 같은 프레임에 여러 마커가 보여도 루트를 여러 번 보정하지 않습니다.

## 완료 조건

마커 1에서 마커 2로 이동하거나 멀리 이동 후 마커를 다시 비췄을 때, 활성 선로 전체가 과도한 떨림 없이 함께 재정렬됩니다.

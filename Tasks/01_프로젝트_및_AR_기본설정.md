# Task 01. 프로젝트 및 Android AR 기본 설정

## 목표

Android 기기에서 `ARScene`을 실행해 카메라 영상과 AR 세션이 정상적으로 시작되는 기반을 만듭니다. 아직 마커와 선로는 구현하지 않습니다.

## 작업

1. Unity Package Manager에서 AR Foundation, ARCore XR Plugin을 프로젝트 Unity 버전에 맞게 설치합니다.
2. Android Build Support가 설치된 Unity Editor를 사용합니다.
3. Build Settings에서 Android로 플랫폼을 전환합니다.
4. Project Settings의 XR Plug-in Management에서 Android의 ARCore를 활성화합니다.
5. `ARScene`에 `AR Session`, `XR Origin`(또는 버전에 맞는 `AR Session Origin`), `AR Camera`를 배치합니다.
6. Android Player Settings의 카메라 권한 문구를 사용자에게 이해되는 문장으로 설정합니다.
7. `LoginScene`에서 `ARScene`으로 이동하는 기존 버튼이 없다면 연결합니다.

## 완료 조건

실제 Android 기기에서 앱을 실행했을 때 카메라 권한을 요청하고, 허용 후 검은 화면이 아닌 카메라 영상이 표시됩니다.

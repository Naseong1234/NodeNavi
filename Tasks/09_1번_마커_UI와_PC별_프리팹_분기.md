# Task 09. 1번 마커 UI와 PC별 프리팹 분기

## 목표

1번 마커를 인식했을 때만 PC 선택 UI를 표시하고, 사용자가 `1번 PC` 또는 `2번 PC`를 선택한 뒤 확인 버튼을 누르면 이후 2~6번 마커에서 선택된 PC 경로용 prefab만 보이도록 확장합니다.

## 구현 대상

- `NodeNavi_Unity/Assets/Data/Scripts/sh_MarkerRouteController.cs`
- 필요 시 새 스크립트
  - `NodeNavi_Unity/Assets/Data/Scripts/sh_MarkerRouteData.cs`
  - `NodeNavi_Unity/Assets/Data/Scripts/sh_PCPathSelectionUI.cs`

## 구현 방향

1. 현재 `markerRoutes` 1세트 구조를 유지하되, 2~6번 마커는 `1번 PC 경로 prefab`, `2번 PC 경로 prefab`을 각각 연결할 수 있게 데이터 구조를 확장합니다.
2. 1번 마커는 경로 분기 기준 마커이므로, 인식 시 추가 UI를 활성화합니다.
3. UI에는 `1번 PC`, `2번 PC` 선택 수단과 `선택 완료` 버튼을 둡니다.
4. 사용자가 PC를 고르면 현재 세션의 경로 모드를 저장합니다.
5. `선택 완료` 버튼을 누르면 UI를 비활성화하고, 이후 2~6번 마커 인식 시 선택된 PC용 prefab만 활성화합니다.
6. 아직 선택하지 않은 상태에서 2~6번 마커를 먼저 인식하면 기본값을 강제로 정하지 말고, 안내 문구로 먼저 1번 마커와 PC 선택을 유도합니다.

## 세부 작업

1. `sh_MarkerRouteData`에 PC별 prefab 참조를 담을 구조를 추가합니다.
2. 1번 마커는 공통 prefab 또는 기존 prefab을 유지하고, 2~6번 마커는 `pc1RoutePrefab`, `pc2RoutePrefab`처럼 두 갈래를 Inspector에서 연결할 수 있게 만듭니다.
3. 런타임 인스턴스도 PC별로 따로 생성해 시작 시 모두 비활성화합니다.
4. `sh_MarkerRouteController`에 현재 선택 상태를 저장할 enum 또는 int 값을 추가합니다.
5. 1번 마커를 인식한 경우에만 `pcSelectionPanel.SetActive(true)`가 실행되도록 합니다.
6. 사용자가 UI에서 `1번 PC` 또는 `2번 PC`를 누르면 선택 상태 텍스트 또는 강조 표시가 바뀌게 합니다.
7. `선택 완료` 버튼을 누르면 선택 UI를 닫고, 현재 선택된 PC 기준으로 이후 경로 표시 로직이 동작하게 합니다.
8. `SetActiveRoutes`는 기존처럼 `routeOrder` 범위를 계산하되, 각 마커에서 현재 선택된 PC에 해당하는 런타임 인스턴스만 활성화합니다.
9. 다른 PC 경로 인스턴스는 같은 구간이라도 반드시 비활성화해 동시에 겹쳐 보이지 않게 합니다.
10. 사용자가 다시 1번 마커를 인식해 다른 PC를 고를 수 있게 허용할지 여부를 먼저 정합니다. 초안 기준으로는 재선택 허용을 권장합니다.

## UI 구성안

1. `ARScene` Canvas 아래에 기본 비활성 상태의 `PCSelectionPanel`을 만듭니다.
2. Panel 안에는 제목 텍스트, `1번 PC` 버튼, `2번 PC` 버튼, `선택 완료` 버튼을 둡니다.
3. 선택 전에는 `선택 완료` 버튼을 비활성화하거나, 누르면 `PC를 먼저 선택해 주세요` 안내를 띄웁니다.
4. 1920 x 1080 기준으로 중앙 또는 하단 고정 배치를 사용해 AR 화면을 과하게 가리지 않게 합니다.

## 사용자 안내 문구

1. 1번 마커 인식 전: `마커를 비춰 주세요`
2. 1번 마커 인식 후, 선택 전: `확인할 PC를 선택해 주세요`
3. 선택 완료 후: `선택한 PC 경로를 표시합니다`
4. 2~6번 마커를 먼저 인식했지만 PC 미선택 상태일 때: `먼저 1번 마커에서 PC를 선택해 주세요`

## Unity Editor에서 사용자가 할 일

1. `ARScene`을 엽니다.
2. `MarkerRouteController` 오브젝트에 PC 선택 UI 참조 필드를 연결합니다.
3. `PCSelectionPanel` GameObject를 만들고 기본 상태를 비활성화합니다.
4. `1번 PC`, `2번 PC`, `선택 완료` 버튼의 `OnClick` 이벤트에 UI 제어 스크립트 또는 `MarkerRouteController` 메서드를 연결합니다.
5. 2~6번 마커 데이터 각각에 `1번 PC용 prefab`, `2번 PC용 prefab`을 Inspector에 할당합니다.
6. 1번 마커 데이터는 분기 기준 마커이므로, 공통으로 쓸 prefab이 있다면 연결하고 없으면 비워도 되는지 코드 규칙에 맞춰 확인합니다.
7. 선택 상태를 보여줄 텍스트나 강조 이미지가 있다면 함께 연결합니다.
8. Android 기기에서 1번 마커 인식 시 UI가 뜨는지, 선택 완료 후 UI가 닫히는지, 이후 2~6번 마커에서 선택한 PC 경로만 보이는지 확인합니다.

## 완료 조건

1. 1번 마커 인식 시에만 PC 선택 UI가 표시됩니다.
2. `1번 PC` 선택 후 2~6번 마커를 비추면 1번 PC용 경로 prefab만 표시됩니다.
3. `2번 PC` 선택 후 2~6번 마커를 비추면 2번 PC용 경로 prefab만 표시됩니다.
4. 선택 완료 버튼을 누르면 선택 UI가 닫힙니다.
5. 선택하지 않은 반대편 PC 경로 prefab은 어떤 구간에서도 동시에 보이지 않습니다.
